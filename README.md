# Подготовка к собеседованию QA — Аксиоматика

Начало: 20 октября 2026. Собеседование ориентировочно через 5–6 дней; точная дата неизвестна.

## Начать здесь
1. Прочитать CONTEXT.md — исходные данные и вакансия.
2. Открыть PLAN.md — программа на 5–6 дней.
3. Посмотреть PROGRESS.md — где остановились.
4. Проходить материалы lessons/ и выполнять задания в evidence/.
5. В конце пройти практику по practice/FINAL_CASE.md, используя шаблоны templates/.

## Цель
Подготовиться к интервью по ручному тестированию web и API. Научиться объяснять проверки и подтверждать выводы фактами. В финале самостоятельно воспроизвести дефект, локализовать его, оформить документацию, проверить исправление и регрессию.

## Текущая точка
Разобраны клиент-сервер, HTTP, выбор проверок, DevTools, ручные запросы и скрипты Postman. Пользователь сообщил о выполнении цепочки POST → GET и прогонов Runner. По просьбе пользователя блок Postman завершён для текущего прохода; разобраны баг-репорты, severity/priority, жизненный цикл и выбор ретеста/регрессии; сейчас — самостоятельная итоговая практика на qa-rc.1. Полная история и границы подтверждения — PROGRESS.md.

## Структура
- AGENTS.md — инструкции для помощника.
- CONTEXT.md — профиль пользователя, пожелания, описание вакансии.
- PLAN.md — последовательность подготовки.
- PROGRESS.md — фактический прогресс и следующий шаг.
- lessons/ — краткая теория и практические задания.
- templates/ — шаблоны документов QA.
- practice/ — условия итогового задания.
- evidence/ — ответы, запросы, скриншоты и результаты ученика; проверки помощника подписаны отдельно.
- demo/ — работающий пример web и API для DevTools и Postman.
- auth-demo/ — отдельный локальный API для входа, токенов и ролей, порт 8766; [контракт и запуск](auth-demo/README.md).

## Продолжение в новом чате
Открыть эту папку как проект в Codex и написать:
«Продолжим подготовку. Прочитай AGENTS.md, CONTEXT.md и PROGRESS.md».
Файлы хранят контекст; автоматический доступ к ним из любого другого чата не предполагается.

Демонстрационный стенд demo-1.0 готов: [запуск и контракт](demo/README.md). Итоговый стенд qa-rc.1 подготовлен отдельно: [задание, требования и API](practice/lab/README.md). Ученик ещё не исследовал его дефекты.
