# Postman: коллекции, окружения и переменные

**На повторение: 4 минуты.** Первый раздел углублённого блока.

## Для чего нужна коллекция
Коллекция объединяет связанные запросы. В ней можно организовать папки, общую авторизацию, переменные и скрипты.
Открытая вкладка — рабочий запрос; Save сохраняет его в выбранное место коллекции.

В подготовленном файле qa-demo.postman_collection.json сохранены прежние ручные запросы и добавлены папки:
- 01 — Цепочка POST → GET: доступность, создание, чтение.
- 02 — Негативные данные: список до, недопустимый POST, список после.

## Окружение
Окружение — набор значений для конкретного стенда. Например, QA Local.
Импортировать postman/qa-local.environment.json и выбрать QA Local в верхнем переключателе окружений.

| Переменная | Значение |
|---|---|
| baseUrl | http://127.0.0.1:8765 |

В запросе использовать {{baseUrl}}/api/applications. Значение адреса подставляется при отправке.
Если адрес стенда меняется, достаточно изменить baseUrl в окружении.

## Где живут значения

| Область | Когда использовать |
|---|---|
| Collection | Значения по умолчанию и несекретные данные цепочки этой коллекции |
| Environment | Адрес и другие настройки выбранного стенда |
| Data | Значения из строки JSON/CSV при прогоне |
| Local | Временное значение для запроса или текущего прогона |
| Global | Общие значения; применять осознанно, чтобы не путать проекты |

При совпадении имени приоритет: local → data → environment → collection → global.
Если baseUrl есть в окружении и коллекции, выбранное окружение имеет приоритет.

## Два разных чтения в скрипте

```javascript
pm.environment.get("baseUrl"); // именно из окружения
pm.variables.get("baseUrl");   // разрешённое значение с учётом областей
```

createdApplicationId наш скрипт сохраняет в collection. Не создавать одноимённую переменную в окружении: это усложнит понимание подстановки.

## Первое действие в приложении
1. Import → выбрать файл коллекции и файл окружения из проекта.
2. Выбрать QA Local.
3. Открыть запрос «01.1 — Стенд доступен».
4. Проверить URL {{baseUrl}}/health.
5. Send: ожидается 200 и build=demo-1.0.

На этом шаге учимся связи коллекция → окружение → подставленный адрес. Остальные запросы разберём отдельно.
Фактический результат пользователя ещё не получен. Импорт в его workspace помощник не выполнял.
