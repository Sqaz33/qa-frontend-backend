# Postman: Runner и наборы данных

**На повторение: 4 минуты.**

## Что делает Runner
Запускает выбранные запросы в указанном порядке, выполняет скрипты и показывает результаты.
Сначала научиться отправлять и понимать запросы вручную, затем запускать папку целиком.

В коллекции две независимые папки. Для цепочки выбирать папку 01, для негативных сумм — папку 02.
Запуск всей коллекции также выполнит старые ручные запросы, включая дополнительное создание на 50000.

## Папка 01 — цепочка
Одна итерация:
1. Проверить доступность.
2. Создать заявку на 1000.
3. Получить её по автоматически сохранённому id.

При повторном запуске создаётся новая заявка — это условие нашего API.

## Папка 02 — негативные данные
Одна итерация:
1. GET: сохранить список.
2. POST: отправить недопустимую сумму.
3. GET: сравнить список и данные с исходными.

Во время прогона не выполнять другие создания: иначе список действительно изменится и проверка зафиксирует отличие.

## Файл negative-amounts.json
Содержит восемь строк: 999, 100001, -1, 0, 1000.5, "1000", null, true.
Каждая строка даёт отдельную итерацию. Все эти суммы недопустимы по контракту.

В Runner выбрать папку 02, подключить файл данных, проверить число итераций 8 и запустить.
Проверять ожидается ли 422, есть ли fields.amount и не изменился ли список.

## Как тело собирается из строки данных

```javascript
const row = pm.iterationData.toObject();
const amount = Object.prototype.hasOwnProperty.call(row, "amount")
  ? row.amount : 999;

pm.variables.set(
  "negativeBody",
  JSON.stringify({name:"test", amount, consent:true})
);
```

Body содержит {{negativeBody}}.
JSON.stringify сохраняет тип значения: число остаётся числом, строка строкой, null не превращается в пустую строку.

## Что означают результаты
- Requests: сколько HTTP-запросов выполнено.
- Iterations: сколько строк/повторов пройдено.
- Assertions: сколько именованных проверок выполнено.
- Failed: что не выполнило ожидания; исследовать сам запрос и конкретное утверждение.

Помощник проверил: папка 01 — 3 запроса, 10 assertions; папка 02 — 24 запроса, 64 assertions, 8 итераций. Ошибок нет. Это ограниченный учебный набор, не полное покрытие продукта.
