# Итоговая практика — локальный стенд

Текущая сборка для ученика: **qa-rc.1**.
Адрес: http://127.0.0.1:8770.
Требования: [REQUIREMENTS.md](REQUIREMENTS.md). API: [API.md](API.md).
Первый рабочий шаг: 8–12 проверок в чек-листе и два подробных тест-кейса.

## Запуск
Python 3.10+; сторонних библиотек нет. Из корня учебного проекта:
```powershell
python practice/lab/server.py --port 8770
```
Сервер слушает только 127.0.0.1. Страница и API работают на одном адресе.
При запуске помощником процесс уже работает в фоне; повторно запускать на занятом порту не нужно.
Проверить доступность: GET http://127.0.0.1:8770/health.
Данные: practice/lab/runtime/applications.sqlite. Не удаляйте базу между проверками; результаты сравнения зависят от её состояния.
Для отдельного эксперимента можно запустить другой порт и другую базу:
```powershell
python practice/lab/server.py --port 8773 --data-dir practice/lab/runtime/experiment
```
Каждый экземпляр должен использовать свою папку данных. Не запускать несколько процессов на одной базе для учебного снимка «до/после».

## Postman
В своём окружении добавьте finalBaseUrl=http://127.0.0.1:8770.
Прежние baseUrl и authBaseUrl не меняйте.
Запросы итоговой практики создавайте в отдельной папке «Итоговая практика».
Готовых проверок, подсказывающих конкретные дефекты, здесь нет.

## Материалы ученика
Папка evidence/final/ содержит пустые формы: checklist.md, test-cases.md, bug-report.md, localization.md, retest-regression.md, release-report.md. Статусы изначально «Не выполнено».
Туда же можно экспортировать свою коллекцию и сохранить очищенные скриншоты/запросы/ответы.

## Порядок
Требования → план проверок → smoke → функциональные проверки web/API → факты и баг-репорт → исправленная сборка → ретест/регрессия → рекомендация по выпуску.
При нескольких отклонениях оформляйте отдельные отчёты для разных проблем.
В ходе работы помощник помогает с инструментами и оценивает ваши доказательства, но не выдаёт причины дефектов заранее.

Стенд учебный. Он отличается от прежнего исправного demo-1.0 и не связан с данными реальных организаций.
