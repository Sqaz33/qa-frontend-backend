# Postman — учебные запросы

Стенд: demo-1.0. Адрес: http://127.0.0.1:8765.
[Запуск стенда и контракт](../demo/README.md).

## Файлы
- qa-demo.postman_collection.json — прежние четыре ручных запроса и две новые папки с проверками.
- qa-local.environment.json — окружение QA Local, переменная baseUrl.
- negative-amounts.json — 8 строк для негативных итераций.
- [DEEP_DIVE.md](DEEP_DIVE.md) — порядок углублённого блока.

Импортировать коллекцию и окружение через Import в приложении, выбрать QA Local.
Первым открыть папку «01 — Цепочка POST → GET» и запрос 01.1 — Стенд доступен.
Тестовые данные синтетические. Секретов в файлах нет.

Каждый успешный POST создаёт новую заявку. Папка 02 проверяет, что отклонённые POST не меняют список.
Результаты помощника — в evidence/postman-advanced-verification.md; практика ученика фиксируется отдельно.
