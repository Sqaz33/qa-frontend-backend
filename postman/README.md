# Запросы Postman

qa-demo.postman_collection.json — коллекция формата 2.1 с четырьмя ручными запросами.
baseUrl по умолчанию: http://127.0.0.1:8765.

Для первых запросов использовать инструкцию notes/06-postman-first-request.md и lightweight API Client без аккаунта.
Коллекцию можно импортировать в workspace, когда он будет доступен. Файл не содержит токенов и персональных данных.

Каждый успешный POST создаёт новую запись. Негативный запрос с amount=999 должен вернуть 422 без создания заявки.
Примеры и ожидаемые результаты не означают, что пользователь уже выполнил запросы.
