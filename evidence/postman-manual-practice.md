## 2026-10-21 — три PASSED в After response
Источник: новый скриншот пользователя, без текстового комментария.
Видно: POST {{baseUrl}}/api/applications, активное QA Local, запрос «02 - Создать заявку», HTTP 201 Created и Test Results 3/3.
Названия пройденных проверок: «Заявка создана: 201», «Сумма - число 1000», «Выдан положительный целочисленный id».
Тело ответа и конкретный id в текущем кадре не видны — не приписывать ему id=7 из предыдущего другого выполнения.

В видимом коде третья проверка записана как pm.test(название, pm.expect(...).to.eql(true)), без функции вторым аргументом. Группа зелёная на этом ответе, но структура требует исправления на pm.test(название, () => { ... }).
Следующий шаг: исправить третий тест, затем временно задать во втором ожидание 999 при неизменном теле amount=1000, увидеть ожидаемый один FAILED и вернуть 1000. Выполнение коррекции и демонстрации пользователем ещё не подтверждено.
