# Проверка углублённой коллекции помощником

Дата: 2026-10-21.
Цель: http://127.0.0.1:8765, живой demo-1.0, не mock.
CLI: Postman 1.75.0. Локальная коллекция формата 2.1, окружение QA Local.
Параметр --no-report-events. Вход и привязка к облачному workspace не выполнялись.

| Прогон | Итерации | Запросы | Assertions | Failed | Exit |
|---|---|---|---|---|---|
| 01 — Цепочка POST → GET | 1 | 3 | 10 | 0 | 0 |
| 02 — Негативные данные | 8 | 24 | 64 | 0 | 0 |

Цепочка: GET /health → POST amount=1000 → GET /api/applications/5.
Фактические статусы: 200, 201, 200. id=5 создан помощником; не смешивать с id=4 из практики пользователя.
Проверены значения name=test, amount=1000, consent=true, status=new, положительный целый id, распознаваемая дата created_at, заголовок Location и совпадение полей при чтении.
Полный формат ISO-даты отдельным строгим шаблоном не проверялся.

Негативный набор: 999, 100001, -1, 0, 1000.5, строка "1000", null, true.
Для каждой строки: GET списка до → POST → GET списка после. POST возвращал 422 и ошибку amount; список и данные оставались прежними.
Проверки пользователя в рамках этого нового набора ещё не выполнялись.

Окружение postman/qa-local.environment.json: lint завершился с exit 0, scanned=1, errors=0, warnings=0.
При подготовке стандартное имя qa-local.postman_environment.json не распозналось командой lint по суффиксу. Файл переименован в qa-local.environment.json без изменения содержимого; после этого lint прошёл. Прогоны использовали то же содержимое окружения.

Первый запуск с --output остановился до выполнения запросов: эта опция требует входа. Повтор без --output завершился успешно. Сообщение о необходимости credentials относится к публикации run details; локальные прогоны имеют exit 0.
Автоматический отчёт в облако не отправлялся.

## Пределы результата
Это проверка учебных запросов и утверждений на конкретной сборке, не полное покрытие API. Не проверялись auth, права, другие методы и производительность.
