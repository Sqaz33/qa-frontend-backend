# Postman — отклонение суммы 999

Дата получения доказательства: 2026-10-21.
Стенд: локальный demo-1.0; на скриншоте URL http://127.0.0.1:8765/api/applications.
Источник: скриншот, присланный пользователем. Версия сборки не показана на скриншоте; demo-1.0 — известный контекст учебного стенда.

## Запрос, видимый на скриншоте
Метод POST. Body raw, выбран JSON.
```json
{
  "name": "test",
  "amount": 999,
  "consent": true
}
```

## Ожидание по контракту
422, error=validation_error и ошибка fields.amount.

## Факт
На скриншоте видны статус 422 и ответ:
```json
{
  "error": "validation_error",
  "fields": {
    "amount": "Сумма: целое число от 1 000 до 100 000 рублей"
  }
}
```

Статус проверки отклонения недопустимой суммы: пройдено.
Подтверждено: пользователь настроил и отправил прямой POST; API вернул ожидаемую ошибку конкретного поля.
Не подтверждено этим скриншотом: отсутствие созданной заявки или других изменений данных. Для этого нужны состояния до и после.

## Доказательство
[Исходный скриншот](screenshots/2026-10-21-postman-amount-999.png).

Показанное предложение Postman AI «Fix the amount field value» не является требованием теста. 999 выбрано намеренно для негативной проверки.

## Следующая проверка — побочные эффекты
1. GET /api/applications → сохранить items, id и поля записей до действия.
2. Повторить тот же POST с amount=999 → ожидается 422.
3. GET /api/applications → сравнить со снимком до действия.
Ожидается: список и данные прежние. Во время проверки другие операции создания не выполнять.

Результат этого сценария от пользователя пока не получен.

## Получен результат проверки отсутствия новой записи
Ответ пользователя — дословно:
> не появилось записи

Контекст: перед ответом дана последовательность GET списка → POST amount=999 → GET списка.
Вывод по сообщению пользователя: после отклонённого запроса новая запись не появилась. Эта часть негативного сценария пройдена.
Пользователь не прислал ответы GET или снимки списков; количество записей, конкретные id и полное совпадение всех полей не установлены отдельно.
