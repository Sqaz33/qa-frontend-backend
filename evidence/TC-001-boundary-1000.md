# TC-001 — Создание и чтение заявки на нижней границе суммы

## Назначение
Проверить включительность нижней границы 1000 и доступность созданной заявки через API.

Требование: целая сумма от 1000 до 100000 рублей включительно; корректные данные позволяют создать заявку.
Контракт: [demo/README.md](../demo/README.md).
Приоритет: высокий для учебного набора — проверяем создание заявки и обработку границы.

## Предусловия
- Доступен сервер demo-1.0.
- Открыт HTTP-клиент Postman.
- Пользователь может отправлять запросы к локальному API; в этом демо авторизация не предусмотрена.
- Готов отдельный запрос GET без тела.

## Данные
```json
{
  "name": "test",
  "amount": 1000,
  "consent": true
}
```

## Шаги и ожидания

| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Отправить POST http://127.0.0.1:8765/api/applications с указанным JSON и Content-Type application/json | 201; в ответе id, name=test, amount=1000, consent=true, status=new, created_at |
| 2 | Сохранить id и тело ответа создания | id доступен для следующего запроса; тело сохранено для сравнения |
| 3 | Отправить GET http://127.0.0.1:8765/api/applications/{id}, подставив полученный id; тело none | 200; получена конкретная заявка |
| 4 | Сравнить id, name, amount, consent, status и created_at с ответом POST | Все перечисленные поля совпадают |

## Постусловия
В стенде остаётся созданная учебная заявка. Каждый успешный повтор POST создаёт новую.
Удаление через API в demo-1.0 не предусмотрено; очистку данных в этой проверке не выполнять.

## Запись выполнения — 2026-10-21
Источник: ответ пользователя после инструкции выполнить POST и GET.
Дословно: «id 4 все совпало».
Факт: получен id=4, пользователь подтвердил совпадение данных при чтении.
Результат сравнения данных: пройдено по сообщению пользователя.
Статусы: 201 и 200 указаны выше как ожидания; пользователь отдельно не назвал фактические коды этого выполнения.
Тела POST/GET и снимки текущего сценария не предоставлены.

id=4 не следует вносить в постоянные шаги тест-кейса: при повторе использовать id новой заявки.
