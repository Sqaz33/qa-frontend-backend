# BUG-F01 — После создания заявки на 99 999 ₽ интерфейс показывает 100 000 ₽

**Статус:** черновик после ревью; уточнение текста учеником ожидается.
**Источник:** отчёт и скриншот ученика. Формулировки ниже уточнены помощником; исходник — bug-report-draft-01.md.
**Дата:** 2026-10-24.
**Сборка:** qa-rc.1 по сообщению ученика; версия в кадре не видна.
**Стенд:** http://127.0.0.1:8770.
**Браузер:** Chrome, версия не предоставлена.
**Требование:** R-07 — точная сумма в результате отправки и списке, без округления.

## Предусловия и данные
Страница создания заявки открыта.
Выполнение на скриншоте: name="Иван12345", amount=99999, consent=true.

## Шаги
1. Открыть http://127.0.0.1:8770.
2. Ввести имя Иван12345 и сумму 99999.
3. Отметить согласие на обработку учебных данных.
4. Нажать «Создать заявку».
5. Сравнить сумму в результате создания и списке с amount в ответе API для той же заявки.

Шаги уточнены помощником по форме и скриншоту. В исходном отчёте ученика указаны только ввод суммы и нажатие кнопки.

## Ожидаемый результат
Успешно созданная заявка отображает точную сумму 99 999 ₽ в результате и списке. API amount=99999.

## Фактический результат
На скриншоте заявка №11 создана:
- форма: 99999;
- ответ API: id=11, name="Иван12345", amount=99999, consent=true, status="new";
- результат на странице: 100 000 ₽;
- строка id=11 в списке: 100 000.

HTTP-статус и метод выбранного запроса в кадре не раскрыты. Ранее ученик также сообщил, что POST/GET дают 99999; это отдельное текстовое сообщение.

## Влияние и оценка
Неверное отображение суммы вводит пользователя в заблуждение.
Severity ученика: Critical, аргумент «главный функционал». Ревью: обоснования для Critical пока недостаточно; предложение помощника — Major по условной шкале, так как нарушено отображение важного значения, но создание/чтение в данном наблюдении доступны.
Priority ученика: High. Предложенное уточнение обоснования — важное финансовое значение показывается неверно в основном сценарии. Решение о блокировке релиза принимается по критериям и процессу команды; оно ещё не зафиксировано.

## Воспроизводимость
Число попыток не указано. Одно выполнение документировано скриншотом; не записывать 3/3.

## Локализация
В ответе API и поле формы сумма 99999, на странице той же заявки 100000. Расхождение проявляется на уровне представления UI; признаки совместимы с округлением.
Точная причина в коде в самостоятельном исследовании ученика не подтверждена. Чтения БД не было; не утверждать, что сохранённые данные испорчены.
Исправленная сборка пока не выдана.
