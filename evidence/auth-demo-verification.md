## Проверки HTTP-контракта
Команда:
```powershell
python -m unittest discover -s auth-demo -p test_auth.py -v
```
Результат: Ran 12 tests, OK, exit=0.

Покрыты: метаданные здоровья, все три защищённых маршрута без входа; недопустимые схемы/токены; вход и профиль; одинаковый отказ для неизвестного пользователя и неверного пароля; ошибки тела/типа; user→403 и admin→200; игнорирование присланной роли/id; отзыв одного токена с сохранением другого; истечение ровно на границе TTL без продления от чтения; неизвестный маршрут.
Для границы срока жизни использован управляемый clock на реальном HTTP-сервере теста, без ожидания 15 минут.
