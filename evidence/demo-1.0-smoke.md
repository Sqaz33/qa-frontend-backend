# Проверка готовности демонстрационного стенда

Дата подготовки: 2026-10-21. Выполнено помощником до пользовательского сценария.
Версия: demo-1.0. Адрес: http://127.0.0.1:8765/.

| Проверка | Фактический результат |
|---|---|
| Синтаксис Python server.py | Проверка пройдена |
| Синтаксис JavaScript app.js | Проверка пройдена |
| GET / | 200, страница содержит «Учебная заявка» |
| GET /health | 200, status=ok, build=demo-1.0 |
| POST с name=Проверка стенда, amount=50000, consent=true | 201, создана заявка id=1 |
| GET /api/applications/1 | 200, данные совпали с ответом создания |
| POST с amount=999 | 422, ошибка amount; количество заявок не изменилось |
| POST с Content-Type=text/plain | 415 |

Результаты получены реальными HTTP-запросами через стандартную библиотеку Python.
Это проверки готовности помощником, не результаты самостоятельной работы ученика.

Автоматизация Chrome была остановлена инструментом: текущий URL не удалось определить с достаточной уверенностью для проверки политики. Автоматический показ в браузере не завершён. Пользователь затем сам выполнил позитивный сценарий по инструкции; его наблюдения — в day-02-devtools.md.
