# Демонстрационный стенд DevTools и Postman

Версия: demo-1.0. Это исправный отдельный учебный пример, не финальное задание с неизвестным дефектом.

## Запуск
Нужен установленный Python 3.10+; дополнительных пакетов нет.

Из корня проекта:
```powershell
python demo/server.py --port 8765
```

Открыть http://127.0.0.1:8765.
Остановка запущенного в терминале сервера: Ctrl+C.
Сервер слушает только 127.0.0.1. Данные сохраняются в demo/runtime/applications.sqlite и не коммитятся.

## Требования
Имя — строка, после обрезки пробелов 2–50 символов.
Сумма — JSON integer от 1000 до 100000 рублей включительно; строки, bool, null и дроби не принимаются.
Согласие — JSON true.
Клиентская HTML-валидация блокирует отправку пустых/недопустимых по HTML полей. Сервер независимо проверяет данные.
Каждый успешный POST создаёт новую заявку. Идемпотентность и защита от повторной отправки не предусмотрены контрактом.
Авторизация в этом демонстрационном API не предусмотрена.

## API
- GET /health → 200: status, build.
- POST /api/applications: Content-Type application/json; тело name, amount, consent.
- Успех → 201: id, name, amount, consent, status=new, created_at. Заголовок Location содержит путь заявки.
- Ошибки полей → 422: error=validation_error, fields с сообщениями. Заявка не создаётся.
- Некорректный JSON/объект или размер тела → 400.
- Неподдерживаемый Content-Type → 415.
- GET /api/applications → 200: items — список заявок, новые первыми.
- GET /api/applications/{id} → 200: заявка, либо 404.
- Неизвестные пути → 404; иные HTTP-методы этим сервером не реализованы.
- JSON-ответы содержат X-Build-Version и X-Request-Id.
- created_at — время UTC в ISO-формате.
- Дополнительные поля JSON игнорируются.

## Пример запроса
```json
{"name":"Тестовый пользователь","amount":50000,"consent":true}
```

## Что показываем в браузере
DevTools открыть до отправки формы. Network → Fetch/XHR → отправить форму → выбрать applications → Headers/Payload/Response.
Имя, сумма, id и версия в документации/доказательствах должны соответствовать реальному выполнению.
